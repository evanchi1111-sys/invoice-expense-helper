# 發票報支小幫手

拍下（或選取）發票照片，自動讀取電子發票 QR Code，產生可直接複製貼上到報支系統的文字。

單一 HTML 檔，**完全離線**可用（已內嵌 QR 讀取程式），不需下載任何語言包。

## 使用方式
1. 下載 `invoice-helper.html`（或 `invoice-helper.zip`），用 Chrome / Edge 開啟。
2. 按「拍照 / 選擇發票」或「從相簿選取」。一張照片可放多張發票（請排開、QR Code 清楚入鏡）。
3. 自動填入：發票種類、發票號碼、發票日期、稅率、統一編號、稅前金額、稅額。
4. 核對後按「複製」，貼進報支系統（預設一列一張、Tab 分隔）。

## 功能
- 讀取電子發票左側 QR Code（號碼、日期、金額、買賣方統編）
- 一張照片多張發票分開辨識，重複發票號碼自動略過
- 買方統編必須為 `84613756`，不符者紅色警告
- 日期格式（民國／西元）、統編（賣方／買方）、輸出格式可選
- 稅率：5%含稅／零稅／免稅；發票種類：25、21、22-B、39

## 限制
- 沒有 QR Code 的點陣紙本發票、手寫發票無法自動辨識，會建立空白記錄請手動填寫。
- 資料只在瀏覽器內處理，不會上傳；記錄存在該瀏覽器，換電腦看不到。
